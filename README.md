## 📖 Про проєкт

**Weather View** — легкий і швидкий застосунок для перегляду поточної погоди в будь-якому місті світу. Введіть назву міста — і отримайте актуальні дані про температуру, відчутну температуру, вологість, тиск та швидкість вітру з наочною іконкою погодних умов.

## ✨ Можливості

- 🔍 Пошук погоди за назвою міста
- 🌡️ Поточна температура та відчутна температура
- 💧 Вологість повітря
- 🌬️ Швидкість вітру
- 🌊 Атмосферний тиск
- 🖼️ Іконка та опис поточних погодних умов
- 💾 Збереження обраного міста
- 📱 Адаптивний дизайн для мобільних пристроїв

## 🚀 Швидкий старт

### Вимоги

- Node.js 18+
- npm

### Встановлення

```bash
git clone https://github.com/dkDevHub/weather-view.git
cd weather-view
npm i
```

### Запуск у режимі розробки

```bash
npm run dev
```

Застосунок буде доступний за адресою [http://localhost:3000](http://localhost:3000).

### Збірка для продакшену

```bash
npm run build
npm run start
```
